No question trips up intermediate French learners more reliably than the choice between **passé composé** and **imparfait**. Both refer to the past, but they describe fundamentally different *types* of past events — and conflating them changes the meaning of what you say.

## The Core Distinction

| | Passé Composé | Imparfait |
|---|---|---|
| **Type** | Completed action | Ongoing state / habit |
| **Time frame** | Specific moment, defined duration | Background, indefinite duration |
| **Role in narrative** | Foreground — what happened | Background — the setting |

## Passé Composé

The passé composé describes **completed actions** with a clear beginning and end.

Use it for:
- Events that happened at a specific moment: *hier, j'ai vu Marie*
- Actions repeated a **defined** number of times: *j'ai relu ce chapitre trois fois*
- Events that **interrupt** an ongoing state: *le téléphone a sonné*

```
Formation: avoir / être + past participle
j'ai mangé, tu es parti, elle s'est levée
```

## Imparfait

The imparfait describes **ongoing states, habitual actions**, and background conditions.

Use it for:
- States of being: *il était fatigué, le ciel était gris*
- Habitual past actions: *quand j'étais enfant, je lisais beaucoup*
- Background in a narrative: *il pleuvait quand nous sommes arrivés*

```
Formation: stem from nous present + endings
-ais, -ais, -ait, -ions, -iez, -aient
```

## Both Together

The two tenses appear together constantly — imparfait sets the scene, passé composé delivers the events:

> *Je **lisais** tranquillement quand soudain la porte **s'est ouverte**.*
> (I was reading quietly when suddenly the door opened.)

The *lisais* (imparfait) establishes the ongoing background; *s'est ouverte* (passé composé) is the discrete event that disrupts it.

## The English Test

When you're unsure which tense to use, ask yourself:

- Could I replace it with **"used to"** or **"was doing"**? → **Imparfait**
- Does it sound like a **news headline** — a discrete, reportable event? → **Passé composé**
